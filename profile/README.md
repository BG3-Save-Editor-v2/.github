## 📖 Overview

**Baldur's Gate 3 Save Editor** is a lightweight Windows utility for editing and managing **Baldur's Gate 3 save files** without having to manually work with complex save data.

The editor is designed for players who want greater control over their BG3 campaigns. You can use it to correct progression issues, customize character data, adjust inventory, modify companion information, experiment with quest outcomes, or inspect and change supported world-state data.

With automatic backups and built-in validation, the **BG3 Save Editor** provides a streamlined way to modify saves while reducing the risk of accidentally losing your original progress.

### Why use a BG3 save editor?

Manually editing Baldur's Gate 3 save data can be complicated and error-prone. This tool provides a more accessible workflow with dedicated editing controls, automatic backups, and a straightforward Windows interface.

# 🔒 Automatic Save Backups

Protecting your existing progress is a core part of the save-editing workflow.

Before modifying a save, the editor can create a backup of the original file so you have a recovery point if an edit produces an unexpected result.

### Backup Features

* Timestamped backup files
* Original save preservation
* Backup restoration
* Dedicated backup directory
* Automatic management of older backups

Example backup filename:

```text
SaveName_yyyyMMdd_HHmmss.bak
```

This makes it easier to identify previous versions of a save and recover an earlier state when necessary.

# 🛡️ Safe Save Editing

Save editing can affect more than a single character or item. Changing the wrong value may influence quests, companions, story progression, or other parts of a campaign.

The editor therefore emphasizes:

* Automatic backups before modifications
* Validation of supported changes
* Clear editing controls
* Preservation of original save data
* A simple review-and-save workflow

No save editor can guarantee that every modification will be compatible with every game update or campaign state. Always keep backups of saves that matter to you.

# 🧰 Troubleshooting

### The editor cannot find my save

Make sure Baldur's Gate 3 has created at least one save and that the application has access to your save directory.

You can also manually select the appropriate save folder if automatic detection does not locate it.

### My edited save does not load

Restore the most recent backup and test the save again. If the original save works correctly, reapply your modifications individually to identify the change causing the problem.

### Can I edit every value in a BG3 save?

Not necessarily. Save formats and supported fields can change between game versions, and some values may not be safe or practical to modify. The available editing options depend on the current version of the editor.

### Should I back up my saves?

Yes. Always keep a backup of important **Baldur's Gate 3 save files** before making substantial changes.
